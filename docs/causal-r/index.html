Каузальный анализ в R на данных RLMS-HSE

Прикладной курс для магистрантов и аспирантов

О курсе

Курс отвечает на один вопрос: как по наблюдательным данным оценить причинный эффект и не обмануть себя. Формулы сведены к минимуму (нотация потенциальных исходов), упор — на дизайн исследования, код в R и интерпретацию. Все примеры — на данных RLMS-HSE, российского лонгитюдного мониторинга домохозяйств.

Каждое занятие (≈90 минут): 20 минут «что это и в чём смысл», 50 минут живого кода на RLMS, 20 минут «как ошибаются» и мини-задача.

Две сквозные линии

Одни и те же вопросы решаются на протяжении курса разными методами, чтобы была видна «лестница оценок» одного эффекта:

  • Образование → зарплата: OLS → мэтчинг → IPW/AIPW → FE → IV → модель Хекмана → медиация → causal forest → чувствительность.
  • Рождение ребёнка → занятость женщин: event study → DiD по материнскому капиталу → RD → IV Ангриста–Эванса → гетерогенность.

Естественные эксперименты курса

Пенсионная реформа 2019 (когортное повышение возраста), порог пенсионного возраста 55/60, пол первых двух детей (Ангрист–Эванс); материнский капитал 2007 — как пример, где DiD не проходит проверку предтрендов. Антитабачный закон и региональные ограничения алкоголя предложены как темы проектов.

Как пользоваться

Слайды открываются по ссылкам в таблице (reveal.js: стрелки — навигация, Esc — обзор, S — заметки лектора, ? — все клавиши). Исходники лекций — файлы .qmd в папке causal-r/lectures/; каждая лекция самодостаточна: source("causal-r/R/load_panel.R") в начале подгружает панель, пакеты и оформление.

Данные

Данные RLMS-HSE студенты скачивают самостоятельно после регистрации на сайте проекта; их редистрибуция запрещена. Курс даёт скрипты: R/01_extract_rlms.R извлекает нужные столбцы из объединённого файла индивидов (и детей по файлу родственников), R/02_recode_panel.R чистит коды и строит аналитические переменные, R/build_rlms_panel.R запускает оба шага, R/load_panel.R подгружает панель в каждой лекции. Переменные панели описаны в лекции 0.
