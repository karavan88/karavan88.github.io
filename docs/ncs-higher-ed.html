Non-Cognitive Skills and Higher Education Completion: Results

Longitudinal Evidence from RLMS-HSE (2016–2024)

1. Sample

Design. We pool baseline observations from waves 25–27 (2016–2018) of the RLMS-HSE. For each person, we take their first eligible observation at age 14–20 with valid Big Five scores and no tertiary education completed yet. We then follow them through all subsequent waves up to wave 33 (2024). The outcome is binary: whether the respondent’s highest completed education level is tertiary at their latest follow-up observation where age ≥ 22. The baseline age range (14–20) follows Heckman, Stixrud & Urzua (2006), who used ages 14–23 in the NLSY.

make_balance <- function(data, group_var = NULL) {
  if (!is.null(group_var)) data <- data |> group_by(.data[[group_var]])
  data |>
    summarise(
      n          = n(),
      age_mean   = round(mean(bl_age), 2),
      age_sd     = round(sd(bl_age), 2),
      pct_female = round(100 * mean(bl_sex == "Female", na.rm = TRUE), 1),
      pct_urban  = round(100 * mean(bl_area %in% c("City", "Regional Center"),
                                    na.rm = TRUE), 1),
      pct_rural  = round(100 * mean(bl_area == "Rural", na.rm = TRUE), 1),
      pct_in_uni = round(100 * mean(bl_in_uni == 1, na.rm = TRUE), 1),
      O_mean     = round(mean(O_bl), 2),
      C_mean     = round(mean(C_bl), 2),
      E_mean     = round(mean(E_bl), 2),
      A_mean     = round(mean(A_bl), 2),
      ES_mean    = round(mean(ES_bl), 2),
      .groups    = "drop"
    )
}

3. NCS Differences by Outcome

ncs_tests <- lapply(NCS_TRAITS, function(trait) {
  bl_col <- paste0(trait, "_bl")
  x1 <- analytic |> filter(tertiary == 1) |> pull(!!sym(bl_col))
  x0 <- analytic |> filter(tertiary == 0) |> pull(!!sym(bl_col))
  tt <- t.test(x1, x0)
  tibble(
    Trait     = trait,
    `Mean (Tertiary)` = round(mean(x1), 3),
    `Mean (No Tert.)` = round(mean(x0), 3),
    Diff      = round(mean(x1) - mean(x0), 3),
    `t`       = round(tt$statistic, 3),
    `p`       = round(tt$p.value, 4),
    `Cohen's d` = round((mean(x1) - mean(x0)) / sqrt((var(x1) + var(x0)) / 2), 3)
  )
}) |> bind_rows()

fit_stats <- function(m, label) {
  ll  <- as.numeric(logLik(m))
  ll0 <- as.numeric(logLik(update(m, ~ 1)))
  tibble(Model = label, N = nobs(m), Events = sum(m$y),
         AIC = round(AIC(m), 1), `McFadden R²` = round(1 - ll/ll0, 4))
}

7. Summary

  1. Sample: 1,821 baseline respondents aged 14–20 from waves 25–27 (2016–2018), of whom 773 are observed at age ≥ 22 in follow-up. 262 (33.9%) completed tertiary education. 21.3% were already enrolled in university at baseline.

  2. Agreeableness is the most robust NCS predictor — negatively associated with tertiary completion across all four specifications: M1 OR = 0.85 (p = 0.056), M2 OR = 0.78 (p = 0.012), M3 OR = 0.72 (p = 0.002), M4 OR = 0.77 (p = 0.001). AME = −5.1 pp. The effect strengthens with controls and IPW correction, and holds across all robustness checks.

  3. Openness is positively associated with tertiary completion across all specifications: M1 OR = 1.34 (p = 0.002), M2 OR = 1.32 (p = 0.012), M3 OR = 1.30 (p = 0.029), M4 OR = 1.30 (p = 0.004). AME = +3.9 pp. Cohen’s d = 0.28 in the raw comparison. The effect is robust to region FE and baseline enrollment controls.

  4. Conscientiousness shows a positive raw difference (d = 0.17, t-test p = 0.024). With region FE it becomes significant in M2 (OR = 1.29, p = 0.014), attenuates in M3 after controlling for university enrollment (OR = 1.22, p = 0.076), and strengthens again under IPW correction in M4 (OR = 1.32, p < 0.001).

  5. Baseline university enrollment is the single strongest predictor: AME = +41.0 pp (p < 0.001). Controlling for it is critical given the 14–20 age range — it absorbs the age effect and sharpens the NCS estimates.

  6. McFadden R² jumps from 0.15 (M2) to 0.27 (M3) when adding baseline enrollment — confirming that current educational trajectory is the dominant predictor, while NCS add incremental predictive power beyond enrollment status. Region FE alone substantially improve model fit (R² = 0.02 in M1 → 0.15 in M2).

  7. Attrition: no NCS trait significantly predicts whether a person is observed at age ≥ 22 after controlling for region FE. The IPW correction in M4 nevertheless strengthens the Conscientiousness and Agreeableness estimates.
