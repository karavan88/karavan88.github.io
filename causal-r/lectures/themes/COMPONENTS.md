# Компоненты темы курса (causal.scss + causal-ui.html)

Тема подключена в `causal-r/lectures/_metadata.yml` — в YAML лекций ничего добавлять не нужно.
Слайд 1280×720. Метка «03 · КОД» над h2, оглавление разделителей, кружки у нумерованных списков,
полоса «ГЛАВНОЕ» у `.thesis` — появляются автоматически.

## Плитки с числами (ключевые цифры, «пример занятия», итог оценок)

```markdown
::: {.tiles}
::: {.tile .navy}
[`r format(nrow(d), big.mark = " ")`]{.v} [наблюдений, RLMS 2016]{.l}
:::
::: {.tile}
[0.25]{.v} [отдача от диплома, лог]{.l}
:::
:::
```
3–4 плитки в ряд. Первая — `.navy` (главная). Числа — только из текста лекции или из инлайн-`r`.

## Шаги процесса (алгоритм, этапы, «как делаем»)

```markdown
::: {.steps}
::: {}

:::
::: {}
**Остатки** на отложенных фолдах
:::
::: {}
```

3–5 шагов, каждый короткий (≤ 15 слов). Номера ставятся сами.

## Переворачивающиеся карточки (вопрос → ответ, ошибка → лекарство, понятие → определение)

```markdown
::: {.flips}
::: {.flip}
[ловушка 1]{.k}

### Лицевая сторона

Короткий вопрос / формулировка

---

**Оборот:** ответ / объяснение
:::
:::
```
Разделитель лицо/оборот — строка `---` внутри `.flip`. 2–4 карточки в ряд. Хорошо для «Мини-задачи», «Как ошибаются», квизов.

## Вкладки (результат / код; разные спецификации; разные группы)

````markdown
```{r}
#| include: false
#| cache: true
# тяжёлый расчёт сюда, чтобы вкладка «Результат» могла идти первой
```

::: {.panel-tabset}
### Результат

```{r}
#| echo: false
график или таблица
```

### Код

```{r}
#| eval: false
тот же код для показа
```
:::
````
Порядок исполнения чанков = порядок в документе. Если вкладка «Результат» стоит первой, а расчёт в «Коде» — вынесите расчёт в скрытый чанк перед tabset, а в «Код» положите копию с `eval: false`.
Подходит, когда на слайде длинный код + график/таблица, или сравниваются 2–3 варианта (женщины / мужчины; OLS / FE / IV).

## Мелочи

- `[ATT]{.pill}`, `[значимо]{.pill .navy}`, `[осторожно]{.pill .warn}` — бейджи в тексте.
- `::: {.callout-important appearance="minimal"}` — красная лента предупреждения.
- `{.smaller}` у заголовка слайда — плотные списки.
- `{.fragment .fade-up}` на карточках/плитках — постепенное появление (не злоупотреблять).

## Стандартный блок «Как читать вывод» (обязателен для ключевых функций лекции)

Образец: `13-heckman.qmd`, слайды «Как читать вывод `selection()`» и «Шаблон вывода для статьи».

1. Слайд `## Как читать вывод \`fun()\`` с вкладками:
   - `### Вывод R` — настоящий вывод функции (`summary()`, `print()`, `etable()`), при необходимости
     обрезанный до ключевых строк через `cat(capture.output(...)[строки], sep = "\n")`.
   - `### С пояснениями` — `::: {.cards .c3}` из 4–6 карточек с метками `[1 · шапка]{.k}`, `[2 · …]{.k}`:
     что означает каждый блок/строка/столбец, в каких единицах, какой тип ошибок, откуда N,
     последняя карточка `.warn` — «сигналы беды» (что в выводе должно насторожить).
2. Слайд `## Как писать результат` — `::: {.card .tint}` с меткой `[шаблон]{.k}` и фразой для статьи,
   где все числа подставлены inline-`r` из объектов лекции; ниже 1–2 пункта: что обязательно назвать
   (допущение, estimand, тип ошибок), чего не писать.
