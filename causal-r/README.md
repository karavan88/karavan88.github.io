# Каузальный анализ в R на данных RLMS-HSE

Структура:

- `index.qmd` — программа курса (страница сайта)
- `lectures/NN-*.qmd` — лекции, рендерятся в reveal.js (`lectures/_metadata.yml` задаёт общие настройки; `lectures/theme.scss` — тема)
- `R/build_rlms_panel.R` — сборка учебной панели из сырых файлов RLMS (путь в `RLMS_PATH`)
- `R/load_panel.R` — подгрузка панели в лекциях
- `data/` — локальные данные, в git не попадают

Рендер: `quarto render` из корня сайта (или кнопка Render в RStudio). Для лекций включён `freeze: auto`:
результаты R-чанков кэшируются в `_freeze/` и должны быть закоммичены, чтобы сайт собирался без данных RLMS.
